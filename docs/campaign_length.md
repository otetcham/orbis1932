# キャンペーン長（1932年3月開始）

- **開始:** `SCENARIOS.era_1932`（1932年3月）
- **最長プリセット:** 70ターン → **1937年12月**（`ERA_FULL_TURNS`）
- **指定方法:** ロビー `campaign-length`、または `Orbis.start({ maxTurns: 70 })` / `Orbis.start({ endYear: 1937, endMonth: 12 })`
- **セーブ:** `orbis_campaign_v5` は `maxTurns` 12〜70 を受理（旧 12/24/36 セーブはそのまま読込）
