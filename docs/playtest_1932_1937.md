## 5. バグ・停止・史実乖離・バランス（重い順）

1. **【重大・設計】キャンペーン最長36ヶ月** — 1937年までの依頼期間を **1セッションでカバーできない**。エンディング・長期史実（盧溝橋・二・二六）の実プレイ検証が不可能。
2. **【重大・史実】`HISTORICAL_TIMELINE_EVENTS`（シャム立憲革命等）は LLM プロンプト用** — モック／未指示時は **UI記事・自動効果に反映されない**。6月革命・連盟脱退を「史実どおりに見る」目的に対しギャップ大。
3. **【重大・バランス】モック裁定の固定 `delta` + 利益集団毎月低下** — 3年弱で安定度・各派支持が崩壊レベル。**本物 AI でも同様の偏りが出るかは未検証**だが、`-1` 系エフェクトの累積設計は要レビュー。
4. **【中】`WORLD_EVENT_DB` の月次記事化** — モックは「年内イベントを2件」拾うのみで、**暦月と無関係**（例: 1932年各月に満州国建国が重複）。本番 LLM でも `calendarNotes` 遵守は要確認。
5. **【中】国内行動と世界ニュースの分離** — シャム立憲化・日本脱退準備を提出しても、**専用の国内記事・条約・緊張変化が発火しない**（モックが空配列）。
6. **【軽】プレイテスト自動化** — 初回はブリーフィング電報2件でバリデーション失敗・ロビー停滞。3件化で解消（手順書に明記推奨）。
7. **【軽・誤検知】`#game-error` の `textContent` に「AI設定」「閉じる」ボタン文言が含まれる** — 自動ログが「エラー36件」になりうる。実際の停止はなし。

**停止・クラッシュ:** なし（両キャンペーン完走、最終 HUD 1935年2月）。

**問題時スクリーンショット:** 誤検知を除き特記事項なし。参考: `/opt/cursor/artifacts/playtest-issue-siam-turn34.png`（終盤 UI）。

## 7. 改善提案（優先順位・実装は本タスク対象外）

1. **ゲーム長 / シナリオ分割** — 1932〜1937をカバーする **60〜72ターン**、または「1932-35」「1935-37」連結セーブ。依頼プレイテストの前提を満たす最優先。
2. **タイムラインイベントのエンジン直結** — `HISTORICAL_TIMELINE_EVENTS` を月進行時に **記事＋任意効果**として発火（LLM に委ねない）。シャム6月・日本3月脱退・1937盧溝橋を acceptance criteria に。
3. **`WORLD_EVENT_DB` の月次フィルタ** — 裁定後記事を `event.date` の年月で選び、重複掲載を抑制。`calendarNotes` と表示を一致させる。
4. **裁定バランス監査** — 利益集団・安定度の月次変動に **フロア／減衰**、難易度別キャップ。長期プレイ（36ターン）スモークを CI に。
5. **オフライン回帰** — `scripts/playtest_1932_1937.mjs` を公式手順化し、モック BRIEFING は **電報3件＋`replace: true` 開始**を固定。
6. **本番 LLM スポットチェック** — 上記1〜3を直した後、シャム1932年6月・日本1933年3月・1937年7月の **非モック1ターン**（鍵はローカル）で `calendarNotes` 遵守を検証。
