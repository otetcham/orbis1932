# 月次裁定の数値上限（`MONTHLY_RULING_CAPS`）

`orbis_game.js` の定数。1回の GM 裁定（`delta` と提出行動の `effects`）から生じる変化を抑え、単月のスパイクで即ゲームオーバーにならないようにする。

## 裁定 JSON 1件あたり（検証時にクリップ）

| キー | delta 上限 | action effects 上限 |
|------|------------|---------------------|
| mil / eco | ±4 | ±4 |
| stb | ±4 | ±4 |
| treasury | ±10 | ±10 |
| prestige | ±3 | ±3 |
| tension | ±5 | ±5 |

## delta + effects 合算後（`applyEvaluation`）

| キー | 合算上限 |
|------|----------|
| mil / eco / stb | ±5 |
| treasury | ±12 |
| prestige | ±4 |
| tension | ±6 |

## 国内利益集団（1グループ・1か月）

- `groups[].delta`: ±4

## 適用後の月次フォール（構造要因込みの結果に対する床/天井）

| 指標 | 1か月あたり |
|------|-------------|
| 財政余力（`treasury`） | 最大 **12** ポイント下落（月初＋当月収支ベース） |
| 国際緊張（`tension`） | 最大 **+7** 上昇 |
| 安定度（`stb`） | 最大 **6** 低下 |
| 経済（`eco`） | 最大 **5** 低下 |

（軍事 `mil` は列強との差を保つためフォールなし。`validateEvaluation` / 維持費ロジックは従来どおり。）

## ゲームオーバー猶予

- `stress.collapse` / `bankruptcy` / `war` はいずれも **3か月連続** で敗北（以前は 2か月）。
- 閾値: 安定度または経済 ≤8 / 財政余力 0 / 国際緊張 ≥95。
